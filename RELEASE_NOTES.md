## Quiz Learning Pro v2.0.0

### What's Changed

#### In-App Auto Update
* Seamless in-app updater with background download and real-time progress.
* SHA-256 checksum integrity verification prior to installer execution.
* Automatic installer lifecycle preserving local SQLite databases and user progress.

#### Core Platform & Performance
* Optimized SQLite storage and queries for large question banks.
* Improved cold startup performance and memory management on Windows.
* Enhanced Firebase cloud sync reliability across devices.

#### Exam Engine & Question Management
* Offline text-to-quiz parser supporting copy-pasted content from Word and PDF documents.
* Two-step review and editing interface before importing questions.
* Enhanced Leitner 5-box spaced repetition engine and timed mock exam modes.

### Installation & Updates
* **Existing installations**: Click **Update Now** in the in-app notification to upgrade automatically.
* **New installations**: Download and run `QuizLearningPro_Setup.exe` from the assets below.
